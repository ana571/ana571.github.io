This small app was made to help create machine knitting patterns. This was 100% vibe-coded.
\newline
Insert your gauge, either in stitches/rows per 10 centimeters or in centimeters per 30 stitches/rows. Choose the size of the grid. By default, the size is 200, corresponding to a 200 needles bed. The default view is a "half mode", where you see the right half of the needles, from 0 to 100.
\\\\
Create your pattern by holding shift and clicking on stiches. The vertical axis at 0 is an axis of symmetry, and enabling "Full mode" will show the other half.
\\\\
You can export your drawing to re-import it later with the same gauge.
\\\\
If you want to re-use the same pattern for a different gauge, export points will create a file that stores the information of the pattern in centimeters. When importing the points with a new gauge, it will fit the pattern to the new gauge.
